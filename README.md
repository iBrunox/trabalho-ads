## Sistema particular da empresa de controle de pagamentos

Esse é um sistema de pagamento de uso particular, podendo ser utilizando apenas localmente pelas empresas.
Para utilizar o sistema, basta baixa-lo e abrir em seu dispositivo
Após a instalação precisa validar a chave de acesso criada particularmente para cada empresa
O sistema utiliza linguagem C# e R mantendo a segurança do sistema
